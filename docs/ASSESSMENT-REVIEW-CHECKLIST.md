# Analyst assessment review checklist

- [ ] Confirm repository identity
- [ ] Confirm repository commit
- [ ] Confirm branch/dirty state
- [ ] Confirm assessment scope
- [ ] Review excluded paths
- [ ] Review oversized/unreadable files
- [ ] Confirm assessment completeness
- [ ] Validate production/test/example/generated classifications
- [ ] Validate high-confidence findings
- [ ] Validate structural relationships
- [ ] Review unresolved relationships
- [ ] Validate security-control evidence
- [ ] Validate concern scenarios
- [ ] Review AAC/ASI mapping if supplied
- [ ] Verify no evidence lead is being presented as proven exploitability
- [ ] Review recommendations
- [ ] Review sensitive excerpts
- [ ] Confirm report limitations
- [ ] Record analyst identity/date/version

If exploitability must be demonstrated, move the issue into a separately authorized
active-testing engagement. Vibe Explainer does not establish exploitability.
